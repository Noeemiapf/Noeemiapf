
**Relatório de Validação — Plataforma de Cursos Online**

**1. Objetivo dos testes:**

Este relatório tem como objetivo validar se as funcionalidades essenciais da plataforma —
cadastro, login, catálogo de cursos, inscrição, área do aluno e acompanhamento de progresso — funcionam corretamente e atendem à proposta inicial do projeto.

**2. Testes realizados:**

Para o cadastro de usuário, foi testado o cenário de criar uma conta com dados válidos, com a expectativa de que o usuário fosse criado e redirecionado corretamente.
Descreva aqui o resultado obtido e se o teste passou ou não.

Para o login, o cenário testado foi entrar com email e senha corretos, esperando que o acesso à área do aluno fosse liberado. Descreva o resultado obtido.

Para o catálogo de cursos, testou-se a listagem dos cursos disponíveis, esperando que todos fossem exibidos corretamente. Descreva o resultado obtido.

Para a página de detalhes do curso, o teste consistiu em abrir um curso específico e verificar se as informações eram exibidas corretamente. Descreva o resultado obtido.

Para a inscrição em curso, testou-se se, ao se inscrever, o curso passava a aparecer na área do aluno. Descreva o resultado obtido.

Para a área do aluno, verificou-se se os cursos em que o usuário estava inscrito apareciam corretamente listados. Descreva o resultado obtido.

Para o acompanhamento de progresso, testou-se marcar um conteúdo como concluído e verificar se o progresso era atualizado. Descreva o resultado obtido.
